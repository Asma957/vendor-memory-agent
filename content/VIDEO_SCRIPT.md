# Demo video script (about 90 seconds)

Record the screen with a voice-over. Keep the app on *Compare both* mode with demo data loaded.

| Time | On screen | Voice-over |
|---|---|---|
| 0:00-0:10 | Title slide or app header | "Hi, we are [TEAM NAMES]. This is the Vendor Memory Agent, built on Hindsight for Hack With Hyderabad 3.0." |
| 0:10-0:20 | Memory Panel, Apex Logistics | "A procurement rep has a meeting with Apex Logistics tomorrow. In August, Apex changed the contract: the discount dropped from 5% to 3%, a 6% fuel surcharge appeared, and payment moved from Net 45 to Net 30." |
| 0:20-0:45 | Click *Generate brief* | "We ask both agents for a negotiation brief. Both use the same Hindsight memory. On the left, the Baseline treats every memory as current. On the right, the Smart agent uses only active terms and lists what is outdated, so the rep does not use old pricing." |
| 0:45-1:00 | Expand *Memories recalled* and *Supersession Ledger* | "Here are the memories Hindsight recalled, and the ledger that tells the agent which terms are active and which were superseded." |
| 1:00-1:15 | Add contract update on Sterling Office Supplies | "Now a live update. Sterling fixes paper and toner prices for 12 months. We save it, it is retained in Hindsight, and the old term turns outdated immediately." |
| 1:15-1:30 | Hindsight view tab, then header | "Hindsight also consolidates facts into observations in the background. The agent doesn't just remember. It knows when old terms are outdated. Thank you." |

**Tips:** do one dry run first and pick the vendor where the Baseline gap is clearest. If the Baseline answers correctly, switch to Nimbus Cloud Services.
