"A procurement rep is meeting Apex Logistics tomorrow. If the agent remembers the old deal but not that the contract changed in August, the rep walks in with the wrong pricing."

**0:10-0:30 Before vs after.**

"Left is a normal memory agent that treats every memory as current. Right is our Smart agent, using the same Hindsight memory but aware of supersession."

**0:30-0:45 Memory panel.**
"Active terms are teal. Outdated terms are amber and struck through, with what replaced them. Forgetting is visible."

"The agent doesn't just remember. It knows when old terms are outdated. Powered by Hindsight."
